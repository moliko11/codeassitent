# Chat Template · 开发与使用指南

> 从 [DeepTutor](https://github.com/HKUDS/DeepTutor) Web 前端抽取出的**独立对话界面布局模板**，封装成干净的 Next.js 工程，专供二次开发（二开）。
>
> 保留了 DeepTutor 对话界面的**布局与视觉系统**——侧栏、标题栏、消息列（用户/助手气泡、Markdown + 代码块）、输入框、四套主题切换——并把所有后端耦合（WebSocket、REST、工具调用、能力 gating）替换成一个**模拟数据 Provider**，模拟流式输出。**无需后端**：`npm install && npm run dev` 即可跑起来。

---

## 一、项目位置

模板位于仓库根目录下的 [`chat-template/`](./)：

```
DeepTutor-main/
└── chat-template/        ← 就是这个模板（本文件所在目录）
    ├── app/              # Next.js App Router 页面与全局样式
    ├── components/       # UI 组件
    ├── context/          # 两个 React Context（UI 偏好 + 聊天状态）
    ├── lib/              # 工具函数、主题、模拟数据
    └── ...
```

整个模板是**自包含**的，与 DeepTutor 原始 `web/` 工程无运行时依赖，可独立拷走使用。

## 二、快速开始

### 环境要求
- **Node.js ≥ 18.18**（推荐 20/22）
- npm（或 pnpm / yarn，下文统一用 npm）

### 安装与运行

```bash
cd chat-template
npm install        # 安装依赖
npm run dev        # 启动开发服务器
# 浏览器打开 http://localhost:3000
```

### 常用脚本

| 命令 | 作用 |
| --- | --- |
| `npm run dev` | 启动开发服务器（热更新） |
| `npm run build` | 生产构建（输出到 `.next/`） |
| `npm run start` | 以生产模式运行（需先 build） |
| `npm run lint` | ESLint 检查 |

### 验证
本模板已通过 `tsc --noEmit` 类型检查（零错误）与 `next build` 生产构建（4 个页面静态预渲染成功）。构建产物首页 `/` 体积约 285 kB（First Load JS 391 kB）。

> **构建提示**：在 Windows 上若看到 `@next/swc-win32-x64-msvc not installed` 警告，是 Next 退而使用 WASM 版 SWC（功能正常，仅编译稍慢）。想消除警告并加速可装原生二进制：`npm i -D @next/swc-win32-x64-msvc`（非必须）。

## 五、架构与数据流

整个界面由**两个 React Context** 驱动，互不耦合：

```
RootLayout (app/layout.tsx)
  └─ <ThemeScript/>                  水合前内联脚本，定主题
  └─ <AppShellProvider>              UI 偏好（主题/侧栏/代码块），localStorage 持久化
       └─ <Page>
            └─ <ChatProvider>        聊天状态（消息/会话/流式），目前为 mock
                 └─ <ChatShell>
                      ├─ <Sidebar/>          读 useAppShell + useChat
                      ├─ <ChatHeader/>       读 useAppShell（主题）
                      ├─ <MessageList/>      读 useChat（消息）
                      └─ <Composer/>         读 useChat（发送/停止）
```

### 1. `AppShellContext` —— UI 偏好（纯前端，localStorage）

定义于 [context/AppShellContext.tsx](./context/AppShellContext.tsx)。管理：

| 字段 | 类型 | 说明 | localStorage key |
| --- | --- | --- | --- |
| `theme` | `"snow" \| "light" \| "dark" \| "glass"` | 当前主题 | `chat-template-theme` |
| `sidebarCollapsed` | `boolean` | 侧栏是否折叠 | `chat-template-sidebarCollapsed` |
| `codeBlockTheme` | `"oneDark" \| "oneLight" \| "github"` | 代码块配色 | `chat-template-cbTheme` |
| `codeBlockShowLineNumbers` | `boolean` | 代码块行号 | `chat-template-cbLines` |
| `codeBlockWrapLongLines` | `boolean` | 代码块换行 | `chat-template-cbWrap` |

每个字段都配 `setX` 方法。代码块相关三项**已在 `RichCodeBlock` 中接线生效**，但模板没做设置 UI（见[二开任务 4](#4-给代码块加设置-ui)）。

### 2. `ChatContext` —— 聊天状态（Mock，待替换）

定义于 [context/ChatContext.tsx](./context/ChatContext.tsx)，是**唯一与后端耦合的文件**。对外暴露：

```ts
interface ChatContextValue {
  messages: ChatMessage[];          // 当前消息列
  isStreaming: boolean;             // 是否正在流式输出
  sessions: SessionSummary[];       // 侧栏 Recents 列表
  activeSessionId: string | null;   // 当前会话 id
  sendMessage: (content: string) => void;   // 发一条消息
  stopStreaming: () => void;               // 中断生成
  newChat: () => void;                      // 新建对话
  selectSession: (id: string) => void;     // 切换会话
}
```

数据类型在 [lib/mockData.ts](./lib/mockData.ts)：

```ts
interface ChatMessage {
  id: string;
  role: "user" | "assistant";
  content: string;
  streaming?: boolean;     // 助手消息正在流入时为 true
  createdAt: number;       // 时间戳 ms
}
interface SessionSummary {
  id: string;
  title: string;
  updatedAt: number;
}
```

**Mock 行为**：`sendMessage` 把用户消息和一条空助手消息（`streaming: true`）推入列表，然后用 `setInterval` 每 **28ms** 把 `generateReply()` 返回的固定 Markdown 逐 token 填进助手消息，模拟流式。`stopStreaming` 清掉定时器并把消息标记为完成。

## 六、主题系统（视觉的核心）

**所有颜色都是 CSS 变量**，定义在 [app/globals.css](./app/globals.css)。四套调色板：

| 主题 id | 选择器 | 标签 | 外观 |
| --- | --- | --- | --- |
| `snow` | `.theme-snow` | Default | 纯白中性、蓝色强调（**默认**） |
| `light` | `:root` | Cream | 暖米白、赤陶色强调 |
| `dark` | `.dark` | Dark | 暖近黑、赤陶色 |
| `glass` | `.theme-glass`（外加 `.dark`） | Glass | 近黑底上的半透明紫 |

每套主题都发布同一组 token：

```
--background  --foreground
--card        --card-foreground
--popover     --popover-foreground
--primary     --primary-foreground
--secondary   --secondary-foreground
--muted       --muted-foreground
--accent      --accent-foreground
--destructive --destructive-foreground
--border  --input  --ring  --overlay
--font-sans  --font-serif
```

**切主题 = 在 `<html>` 上换一个变量块**。所有组件都用 `bg-[var(--card)]`、`text-[var(--foreground)]` 这类 token，所以整界面瞬时换肤。[tailwind.config.js](./tailwind.config.js) 把同样的 token 映射成 Tailwind 工具类（`bg-card`、`text-foreground`、`bg-primary`…），两种写法都可用。

**防闪烁**：[ThemeScript.tsx](./components/ThemeScript.tsx) 是一个内联到 SSR HTML 的 `<script>`，在 React 水合**之前**就从 localStorage 读主题并加上对应 class，避免主题闪烁（FOUC）。它必须是 Server Component。

## 七、组件 API 速查

| 组件 | 关键 props / 依赖 | 说明 |
| --- | --- | --- |
| `Sidebar` | 读 `useAppShell` + `useChat` | 220px 展开 / 60px 折叠；主导航 4 项、次导航 3 项、Recents 会话列表、GitHub 链接。**导航项是纯视觉，无路由** |
| `ChatHeader` | `title: string`、`onRename: (s)=>void` | 点标题可编辑（Enter 提交，Esc 取消），右侧挂 `ThemeSwitcher` |
| `MessageList` | `onPickSuggestion: (s)=>void` | 空状态 4 个建议词；用户气泡右对齐，助手带 Sparkles 头像 + Markdown + 复制按钮；流式时显示"正在思考…" |
| `Composer` | 读 `useChat` | 自适应高度 textarea（最大 200px，`maxLength=32000`），Enter 发送 / Shift+Enter 换行，**兼容中文输入法**（合成中 Enter 不发送），发送/停止按钮切换 |

| `RichCodeBlock` | `raw: string`、`lang: string` | Prism 高亮，读 `AppShellContext` 的代码块偏好，顶部显示语言名 |
| `ThemeSwitcher` | 读 `useAppShell` | 4 主题弹层，点遮罩关闭 |
| `useChatAutoScroll(deps)` | 传入依赖数组 | 返回 ref；流式时自动吸底，用户上滑距底 >80px 则不再吸底 |

## 八、二次开发（二开）指南

这是本模板的核心用途。下面按常见任务给出**改哪个文件、怎么改**。

### 1. 接入真实后端（最重要）

**只改 [context/ChatContext.tsx](./context/ChatContext.tsx) 一个文件**，UI 无需动。三种主流接法：

**① REST（非流式）**
在 `sendMessage` 里把 mock 的 `setInterval` 段删掉，改为：
```ts
const res = await fetch("/api/chat", {
  method: "POST",
  body: JSON.stringify({ messages }),  // 带上历史
});
const data = await res.json();
setMessages(prev => prev.map(m =>
  m.id === assistantId ? { ...m, content: data.reply, streaming: false } : m
));
```
流式感弱但最简单。

**② SSE / WebSocket（流式，推荐）**
保留 mock 的"逐 token 填入助手消息 content"的写法，只是数据来源换成网络：
```ts
// SSE 示例
const res = await fetch("/api/chat", { method: "POST", body: ... });
const reader = res.body!.getReader();
const decoder = new TextDecoder();
let acc = "";
while (true) {
  const { done, value } = await reader.read();
  if (done) break;
  acc += decoder.decode(value, { stream: true });
  setMessages(prev => prev.map(m =>
    m.id === assistantId ? { ...m, content: acc } : m   // 和 mock 的写法一致
  ));
}
setMessages(prev => prev.map(m =>
  m.id === assistantId ? { ...m, content: acc, streaming: false } : m
));
```
**关键**：把每个增量 delta 累加进 `content`，结束时把 `streaming` 置 `false`——和 mock 的 `setInterval` 循环逻辑完全一致。`stopStreaming` 里用 `AbortController` 中断请求。

**③ 会话历史**
- 在 `useEffect` 里从你的 API 拉取 `sessions` 列表填进侧栏；
- 在 `selectSession(id)` 里拉取该会话的 `messages`（当前 mock 只是清空列显示空状态，注释里有说明）。

### 2. 改主题配色
编辑 [app/globals.css](./app/globals.css) 里对应调色板块的 CSS 变量值即可。比如把 `snow` 的 `--primary` 从 `#2563eb` 换成你的品牌色，所有用 `primary` 的地方同步变化。

### 3. 新增一套主题
1. 在 `globals.css` 加一个 `.theme-xxx { --background: ...; ... }` 块；
2. 在 [lib/theme.ts](./lib/theme.ts) 的 `Theme` 类型加 `"xxx"`，并在 `applyThemeToDocument` 里加分支；
3. 在 [components/ThemeScript.tsx](./components/ThemeScript.tsx) 的内联脚本里加对应分支（保证水合前生效）；
4. 在 [components/ThemeSwitcher.tsx](./components/ThemeSwitcher.tsx) 的 `THEMES` 数组加一项。

### 4. 给代码块加设置 UI
`codeBlockTheme` / `codeBlockShowLineNumbers` / `codeBlockWrapLongLines` 三项偏好已在 `AppShellContext` 和 `RichCodeBlock` 全线接通，**只缺一个设置入口**。照 `ThemeSwitcher` 的弹层样式做一个下拉挂到 `ChatHeader` 或 `Sidebar`，调用 `setCodeBlockTheme` / `setCodeBlockShowLineNumbers` / `setCodeBlockWrapLongLines` 即可。

### 5. 换字体（精确还原 DeepTutor）
默认用系统字体栈（离线可构建）。要和 DeepTutor 像素级一致，用 `next/font/google` 引入 Geist + Lora，并设置 `--font-sans` / `--font-serif` 变量。见 [app/layout.tsx](./app/layout.tsx) 顶部注释。

### 6. 调整流式速度
[context/ChatContext.tsx](./context/ChatContext.tsx) 里 `setInterval(..., 28)` 的 `28`（ms）即 token 节奏，调小更快、调大更慢。接入真实后端后这行会被网络流取代，无需关心。

### 7. 改建议词 / 空状态文案
[components/MessageList.tsx](./components/MessageList.tsx) 的 `SUGGESTIONS` 数组（建议词）和 `EmptyState`（标题"有什么可以帮你的？"等文案）。

### 8. 改侧栏导航
[components/Sidebar.tsx](./components/Sidebar.tsx) 顶部的 `PRIMARY_NAV` 和 `SECONDARY_NAV` 数组。若要接真实路由，给 `onClick` 加 `next/link` 或 `useRouter().push()`（当前是单页模板，导航项纯视觉）。

### 9. 改模拟回复内容
[lib/mockData.ts](./lib/mockData.ts) 的 `RICH_REPLY`（富 Markdown 演示回复）和 `SHORT_REPLY`，以及 `SAMPLE_SESSIONS`（侧栏示例会话）。接入后端后这些都可删。

### 10. 加多语言（i18n）
模板为简洁起见移除了 i18n。需要的话装 `react-i18next`，在 `AppShellProvider` 外再套一层 provider，把界面字符串替换为 `t("...")`。

## 九、已知限制

- **单页**：导航项无路由，整站只有一个 `/`。
- **纯 mock**：无任何真实后端，回复是固定的 Markdown。
- **无 i18n**：界面文案为中英混排硬编码。
- **代码块设置无 UI**：偏好已接线但缺设置入口（见二开任务 4）。
- **`selectSession` 不加载历史**：切换会话仅清空消息列显示空状态，需自行接后端恢复历史。

---

## 十、出处与许可

布局、主题 token、组件结构移植自 DeepTutor 的 `web/`（Apache-2.0）。后端逻辑（`UnifiedChatContext`、WebSocket 客户端、工具调用、能力 gating、各类 picker）被**刻意移除**，以保持纯布局模板的定位。
